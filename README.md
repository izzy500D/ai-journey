# My AI & Cybersecurity Learning Notes

## What I Am Learning
I am exploring how Artificial Intelligence works in the cloud and how to keep AI systems safe from hackers.

## 3 Golden Rules for AI Security
1. **Never share secrets with public AI:** Do not paste real passwords, private API keys, or personal data into AI chatbots.
2. **Watch out for Prompt Injection:** Hackers sometimes hide sneaky instructions inside text to trick an AI into ignoring its safety rules.
3. **Check AI answers:** AI can make mistakes, so humans must always verify important security settings before using them in the cloud.

## Cloud Security Lesson 2: IAM (Digital Security Guards)
* **What is IAM?** Identity and Access Management controls who can enter my cloud account and which rooms they can open.
* **Authentication vs. Authorization:** Authentication checks *who you are* (ID badge), while Authorization checks *what you are allowed to do* (which doors open).
* **Principle of Least Privilege:** Always give people and programs the smallest amount of permission needed to do their job.
## Cloud Security Lesson 3: VPCs & Firewalls (Digital Fences)
* **What is a VPC?** A Virtual Private Cloud is my own private, fenced-in space inside the cloud where my servers live safely away from strangers.
* **Public vs. Private Subnets:** Public subnets hold things visitors need to reach (like websites), while private subnets hide secret databases away from the open internet.
* **Firewalls (Security Groups):** Digital bouncers that block all outside traffic by default and only open specific doors (ports) for trusted visitors.
## Cloud Security Lesson 4: Encryption (Secret Codes)
* **What is Encryption?** Scrambling readable data (Plaintext) into unreadable secret code (Ciphertext) that can only be unlocked with a special digital key.
* **Encryption at Rest:** Locking and scrambling files while they sit stored on cloud hard drives and databases.
* **Encryption in Transit:** Protecting data while it travels across the internet (like seeing `https://` in a browser) so hackers cannot spy on it.
## Cloud Security Lesson 5: Logging & Monitoring (Security Cameras)
* **What is Logging?** Recording every single action inside my cloud account (who logged in, what they changed, and when) like security camera footage.
* **What is Monitoring?** Using automated watchdogs to watch those logs 24/7 and send instant alerts when suspicious activity happens.
* **Why It Matters:** Logs help detect attacks in real time and act as detective clues to trace how an intruder got in.
