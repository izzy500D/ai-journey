# My AI & Cybersecurity Learning Notes

## What I Am Learning
I am exploring how Artificial Intelligence works in the cloud and how to keep AI systems safe from hackers.

## 3 Golden Rules for AI Security
1. **Never share secrets with public AI:** Do not paste real passwords, private API keys, or personal data into AI chatbots.
2. **Watch out for Prompt Injection:** Hackers sometimes hide sneaky instructions inside text to trick an AI into ignoring its safety rules.
3. **Check AI answers:** AI can make mistakes, so humans must always verify important security settings before using them in the cloud.
